## Known warnings

### macOS `Messages.g.swift` — non-`Sendable` completion capture

`Messages.g.swift` (generated by Pigeon) emits a Swift concurrency warning about
capturing a non-`Sendable` type in a `@Sendable` closure. The file is generated
code and must not be edited by hand. Builds succeed at all current Xcode / Swift
language-mode settings.

**Do not fix inline.** Revisit when upgrading Pigeon, Xcode, or enabling Swift 6
strict concurrency mode. File a Pigeon issue upstream if the warning persists after
a Pigeon upgrade.
